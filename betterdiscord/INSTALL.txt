WHISPER - plugin de BetterDiscord / BetterDiscord plugin (Windows)
==================================================================

ES
Es un solo archivo (Whisper.plugin.js); no hay que compilar nada. Necesitas Discord y BetterDiscord.

1. Abre PowerShell dentro de esta carpeta (la que contiene install.ps1) y ejecuta:
      powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
   Para solo ver que haria, sin cambiar nada, agrega -DryRun. Con -Yes no pregunta nada (espera sola a que BetterDiscord quede instalado).
2. Discord lo instalas tu: https://discord.com/download (inicia sesion una vez).
3. Si falta BetterDiscord, el script descarga su instalador oficial a %TEMP% y lo abre: elige tu
   Discord, pulsa Install, espera a que termine y vuelve a la ventana de PowerShell a pulsar Enter.
4. El script copia Whisper.plugin.js a %APPDATA%\BetterDiscord\plugins.
5. Reinicia Discord (Ctrl+R) y activa Whisper en Ajustes -> Plugins.

A mano: instala BetterDiscord (betterdiscord.app), arrastra Whisper.plugin.js a
%APPDATA%\BetterDiscord\plugins (o Ajustes -> Plugins -> Abrir carpeta de plugins) y activalo.
Actualizar: sustituye Whisper.plugin.js por el nuevo (o repite el script).
Desinstalar: desactivalo en Ajustes -> Plugins y borra Whisper.plugin.js de esa carpeta.
Problemas: si dice que la ejecucion de scripts esta deshabilitada, usa el comando de arriba (-ExecutionPolicy Bypass).
Sin acceso a GitHub: descarga el instalador desde betterdiscord.app e instala a mano.
Diferencias con la edicion de Vencord: sin voz ligera, sin cerrar transmisiones al dormir y sin aviso de actualizaciones.

Aviso: los terminos de Discord prohiben los mods del cliente; usalo bajo tu propio riesgo.
Este proyecto sera eliminado el dia que salga Discord Phoenix.

EN
It is a single file (Whisper.plugin.js); nothing to compile. You need Discord and BetterDiscord.

1. Open PowerShell inside this folder (the one containing install.ps1) and run:
      powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
   To only see what it would do without changing anything, add -DryRun. -Yes skips all questions (it waits by itself until BetterDiscord is installed).
2. You install Discord yourself: https://discord.com/download (sign in once).
3. If BetterDiscord is missing, the script downloads its official installer to %TEMP% and opens it:
   pick your Discord, click Install, wait for it to finish and press Enter in the PowerShell window.
4. The script copies Whisper.plugin.js to %APPDATA%\BetterDiscord\plugins.
5. Restart Discord (Ctrl+R) and enable Whisper in Settings -> Plugins.

Manual: install BetterDiscord (betterdiscord.app), drag Whisper.plugin.js into
%APPDATA%\BetterDiscord\plugins (or Settings -> Plugins -> Open Plugins Folder) and enable it.
Update: replace Whisper.plugin.js with the new one (or re-run the script).
Uninstall: disable it in Settings -> Plugins and delete Whisper.plugin.js from that folder.
Troubleshooting: if scripts are reported as disabled, use the command above (-ExecutionPolicy Bypass).
No GitHub access: download the installer from betterdiscord.app and install manually.
Differences from the Vencord edition: no light voice, no closing streams when asleep, no update check.

Warning: Discord's Terms of Service prohibit client mods; use at your own risk.
This project will be deleted the day Discord Phoenix is released.
